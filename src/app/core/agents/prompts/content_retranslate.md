셀러가 상세페이지의 한국어 상품명과 상세 설명을 직접 고쳤습니다. 고친 내용을 현지 언어본에 반영합니다.

입력
- target: 언어 코드(vi | en | th)와 현지 작성 지침
- ko: 셀러가 고친 한국어 name, description
- previous: 기존 현지어 name, description (참고용. 표현 스타일을 맞춥니다)

규칙
1. 셀러가 쓴 사실과 뉘앙스를 그대로 옮깁니다. 내용을 더하거나 빼지 않습니다.
2. target 언어로만 씁니다. 브랜드명은 기존 현지어본의 표기를 따릅니다.
3. description 의 단락 구분(빈 줄)을 그대로 유지합니다.
4. name 은 120자 이내입니다.
